# Demo videos

Đặt 2 file video demo vào thư mục này:

- `demo-vi.mp4` — video giới thiệu tiếng Việt
- `demo-ja.mp4` — video giới thiệu tiếng Nhật

Đường dẫn được khai báo trong `DEMO_VIDEOS` tại `src/routes/index.tsx`.
Nếu video được host ở nơi khác (YouTube, CDN, R2…), sửa URL trong `DEMO_VIDEOS` thay vì đặt file ở đây.
